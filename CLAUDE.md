# CLAUDE.md — SHK_Mate Project Guide

This file provides guidance to Claude Code when working with the **SHK_Mate** project.

## Project Overview

**SHK_Mate** is a hybrid mobile/web application built with:
- **Framework**: Capacitor (web app → iOS/Android)
- **Frontend**: HTML5, CSS3, vanilla JavaScript
- **Build**: Node.js / npm
- **Deployment**: Google Play Store (Android)
- **Repository**: https://github.com/NouBou1/SHK_Mate

The app provides calculator and utility functions for scientific/educational purposes.

## Development Workflow

### 1. **Setup & Installation**

```bash
cd B:\developer\ki_tests\shk-mate

# Install dependencies
npm install

# Verify Capacitor is installed
npx cap --version
```

### 2. **Local Development**

```bash
# Run in browser (for testing HTML/CSS/JS)
# Open index.html in a browser, or use a local server:
npx http-server .

# Or simply open index.html directly
```

### 3. **Build for Android**

```bash
# Sync web assets to Android project
npx cap sync android

# Build APK using Android Studio or Gradle
# See: INSTALLATION.md, ANDROID_TEST_REPORT.md
```

### 4. **Deploy to Google Play**

```bash
# See: PLAYSTORE_DEPLOYMENT.md for detailed steps
# Requires:
# - Keystore file (shkMate-release.keystore or shk-mate.jks)
# - Google Play account & Console access
# - Signed APK/AAB
```

## Important Configuration

### Capacitor Config (`capacitor.config.json`)

```json
{
  "appId": "com.shk.mate",
  "appName": "SHK_Mate",
  "webDir": "www",
  "plugins": {
    "SplashScreen": {
      "launchShowDuration": 3000
    }
  }
}
```

### Package Dependencies

- `@capacitor/core@8.x` — Core runtime
- `@capacitor/android@8.x` — Android support
- `@capacitor/cli@8.x` — Build tools
- `@capacitor/filesystem@8.x` — File access
- `@capacitor/share@8.x` — Share functionality
- `@capacitor/status-bar@8.x` — Status bar control

## Security & Keystores

⚠️ **Keystores are credentials** — handle with care:
- `shk-mate.jks` — Java Keystore (older format)
- `shkMate-release.keystore` — Release keystore (current)
- Both files should **NOT** be committed to public repos
- See `SECURITY.md` for password & safety guidelines

## Common Tasks

| Task | How |
|------|-----|
| Fix styling bugs | Edit `style.css` or files in `css/` → Reload browser |
| Add calculation feature | Modify `js/calc.js` → Test in browser → Build Android |

## Debugging

### Browser Console
```bash
# Open browser DevTools (F12) → Console tab
# Check for JS errors, network issues, Capacitor logs
```

### Android Logcat
```bash
# View app logs from device
adb logcat | grep "SHK_Mate"
# Or see: RECHNER_DEBUG_BERICHT.md for detailed logging
```

### Common Issues
- **"app is not defined"** → Check that `app.js` loads before other JS
- **Styles not applying** → Clear browser cache (Ctrl+Shift+Del)
- **Capacitor not found** → Run `npm install` then `npx cap sync android`
- **Android build fails** → Check Java/Gradle versions, see `INSTALLATION.md`
